# Принятые решения

- 26.09.2026: игровая сцена создаётся в Unity URP для компьютера и Android; браузер не является целевой платформой.
- 27.09.2026: Android-приложение состоит из вертикальной Flutter-оболочки и полноэкранной горизонтальной Unity-игры. Первоначальное решение о серверном хранении смены заменено решением об автономном APK ниже.
- 27.09.2026: нижний подробный набор Figma — основной путь приложения; выбор формы берётся из верхнего набора. Системная область Android остаётся нативной.
- 27.09.2026: сначала публикуется очищенная воспроизводимая основа Unity и сервера, затем отдельным изменением добавляется Flutter-оболочка. До появления новых сценариев в программе доступен только первый день.
- 27.09.2026: выпускной Android APK должен открывать полную первую смену без сети и сервера. Профиль, попытки и личный результат хранятся локально; синхронизация с FastAPI откладывается до появления публичного сервера. Общий рейтинг до этого не изображается действующим.
- 27.09.2026: таймеры останавливаются при сворачивании или блокировке телефона; Flutter остаётся вертикальным, Unity — горизонтальной. Первый запуск сохраняет выбор учебного профиля. Выпускной APK распространяется через GitHub Releases, ключ подписи не хранится в Git.

Требования организатора и текущие ограничения перечислены в [матрице требований](requirements.md). Новые продуктовые решения фиксируются здесь отдельно от обязательных условий ТЗ.
