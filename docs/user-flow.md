# Путь пользователя

1. При первом запуске выбирает вымышленный учебный профиль, персонажа и депо. Приложение создаёт профиль через `POST /api/profiles` и сохраняет токен на устройстве.
2. Видит программу обучения: первый день доступен, остальные четыре обозначены как будущие. Прогресс загружается с сервера.
3. Открывает первый день, знакомится с этапами смены и запускает 3D-сцену после её встраивания в Android-оболочку.
4. В игре подходит к цели, получает контекст, выбирает действие и видит последствия. Критическое решение может истечь по таймеру.
5. После смены читает разбор каждого действия, изменения двух шкал, компетенции, достижения и место в рейтинге.

Экраны оболочки основаны на нижней последовательности [макета Figma](https://www.figma.com/design/OCKHKOEylCubp3ekk8ZNeS/%D0%92%D0%A1%D0%9C?node-id=0-1). Макет iPhone задаёт оформление контента; на Android используется системная статусная область устройства.
