# Проводник ВСМ

Учебная игра о рабочей смене проводника высокоскоростного поезда. Игрок готовит вагон, встречает пассажиров, принимает решения в рейсе и получает разбор последствий. Результаты, таймеры и ветвления определяет сервер; Unity показывает поезд и игровые действия.

## Состав проекта

- `unity/` — Unity 6.6.3f1, URP, сцена первой смены для macOS и Android.
- `server/` — FastAPI, движок сценария, сохранение попыток, профиль, достижения, рейтинг и аналитика.
- `docs/` — требования, архитектура, пользовательский путь, исходные материалы и ограничения.
- `app/` — Android-оболочка Flutter: учебный профиль, программа пяти дней, достижения и рейтинг.

## Локальный запуск сервера

```sh
docker compose up -d --build
```

Проверка: `http://127.0.0.1:8080/api/health`. Описание API: `http://127.0.0.1:8080/docs`. По умолчанию сервис доступен только на этом компьютере. Для проверки с телефона в той же сети задайте `GAME_BIND_ADDRESS=0.0.0.0` и укажите LAN-адрес компьютера в игре. Демо использует только вымышленные профили.

Без Docker: установите `uv`, выполните `uv sync --frozen`, затем `.venv/bin/fastapi dev --host 127.0.0.1 --port 8000`. По умолчанию данные сохраняются в локальном SQLite; Docker Compose использует PostgreSQL.

## Игра

Откройте `unity/` в Unity **6000.6.3f1** с Android Build Support. Сцена: `Assets/GameVSM/Scenes/Metallostroy.unity`. Сборочные методы `GameVSM.Editor.NativeBuild.Mac()` и `GameVSM.Editor.NativeBuild.Android()` создают артефакты в `unity/Builds/`, которые не входят в Git. Для получения модели поезда после клонирования требуется `git lfs pull`.

Левый виртуальный джойстик управляет движением на Android, правой частью экрана можно осматривать сцену; кнопки действия появляются рядом с целью. На компьютере — WASD, мышь и клавиши E/F. Сервер должен быть запущен до начала смены. Адрес подключения указывается в интерфейсе игры.

## Android-оболочка

Запустите сервер на порту 8000, затем выполните `cd app && flutter run` на Android-эмуляторе. Приложение обращается к `http://10.0.2.2:8000`; для другого адреса используйте `--dart-define=API_BASE_URL=<адрес>`. На реальном устройстве нужен доступный ему адрес сервера. Данные учебного профиля должны быть вымышленными. Токен хранится в защищённом хранилище Android.

Оболочка и отдельная Unity-сборка пока устанавливаются независимо. Встраивание Unity as a Library и запуск игрового рейса из экрана первого дня — следующий этап.

## Проверка и ограничения

```sh
uv sync --frozen
.venv/bin/python -m pytest -q
.venv/bin/ruff check server tools/check-game-api.py
```

Игра содержит одну полноценную учебную смену. Уровни, рейтинг по бригадам и депо, каталог нескольких сценариев, уведомления о новых заданиях и отдельный контракт HR/LMS ещё не завершены. Android APK собран, но прохождение на физическом телефоне не подтверждено. Учебные решения и баллы — параметры демо, а не утверждённая аттестационная методика.
