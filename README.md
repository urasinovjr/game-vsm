# Проводник ВСМ

Учебная игра о полной смене проводника: приёмка вагона в депо, посадка пассажиров, рейс и сдача вагона в пункте назначения. Игрок перемещается по 3D-сцене, общается с пассажирами, принимает решения в эпизодах с разными последствиями и получает разбор после смены.

Установите [APK для Android](https://github.com/urasinovjr/game-vsm/releases/latest) и откройте приложение. На первом экране создайте вымышленный учебный профиль, затем нажмите «Начать смену». Интернет и отдельный сервер для прохождения не нужны. Прогресс и личный результат сохраняются на телефоне; общий рейтинг появится после подключения синхронизации.

В игре левый джойстик отвечает за движение, движение пальцем по правой части экрана — за осмотр, кнопка «Действие» — за взаимодействие с людьми и предметами. Баллы качества и доверия показывают последствия игровых решений, а не профессиональный допуск.
