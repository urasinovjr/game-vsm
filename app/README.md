# Android-приложение «Проводник ВСМ»

Flutter-оболочка показывает учебный профиль, программу пяти дней, этапы первого рейса, достижения и рейтинг. Профиль, прогресс и рейтинг загружаются из `server/`. Для демонстрации используйте только вымышленные данные.

```sh
flutter pub get
flutter run
```

Для Android-эмулятора API по умолчанию находится на `http://10.0.2.2:8000`. Если сервер запущен в Docker Compose на порту 8080, передайте `--dart-define=API_BASE_URL=http://10.0.2.2:8080`. Для устройства в локальной сети укажите доступный ему адрес. В выпускной сборке используйте HTTPS.

```sh
flutter analyze
flutter test
flutter build apk --debug
```

Экран первого дня пока показывает структуру смены. Запуск 3D-рейса появится после встраивания Unity as a Library.
